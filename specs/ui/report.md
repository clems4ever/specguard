## Behaviour

The report is a browsable UI: a dashboard that orients a reader and groups specs
by area, search, a detail view with code deep-links and screenshot galleries,
and it works hosted under a subpath. The specs below are those behaviours.

## Why

The catalog is only as useful as it is explorable; the interface is what lets a
PM or newcomer actually navigate and trust it.
